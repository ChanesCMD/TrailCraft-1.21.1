# Задача для Claude Code: TrailCraft (NeoForge 1.21.1, modid `trailcraft`)

Проект: мод TrailCraft без MCreator, NeoForge 1.21.1, Java 21.
Этот архив распаковывается **в корень проекта**: его папки повторяют структуру проекта.

## Что в архиве

| Путь | Что это |
|---|---|
| `CLAUDE_TASK.md` | этот файл, с него начинать |
| `docs/TASK_ITEMS.md` | ТЗ, часть 2: инструменты и предметы (52 предмета) |
| `docs/TASK_UI.md` | ТЗ, часть 1: инвентарь, HUD, окна, чат, голосовой чат |
| `docs/ui/*.png` | 12 макетов интерфейса 1920×1080 |
| `docs/preview_all_items.png`, `docs/preview_all_ui.png` | общий вид всех предметов и всех экранов |
| `docs/lang/*.additions.json` | названия предметов на английском и русском, дописать в существующие lang-файлы |
| `src/main/resources/assets/trailcraft/textures/item/` | 63 готовые текстуры предметов |
| `src/main/resources/assets/trailcraft/models/item/` | 63 готовые модели предметов |

Если в проекте уже есть файлы с такими же именами — не перезаписывать молча, сначала показать разницу и спросить.

## Порядок работы

1. **Предметы** (`docs/TASK_ITEMS.md`): регистрация, уровни материалов, модели, названия, творческая вкладка. Это быстрее и не зависит от интерфейса.
2. **Интерфейс** (`docs/TASK_UI.md`) по шагам из его раздела «Порядок работы»: слоты игрока → блокировка → окна рюкзака, пояса, кошелька → календарь → HUD → чат → голосовой чат → кнопки в углу.

После каждого шага: собрать (`./gradlew build`), запустить клиент (`./gradlew runClient`), проверить результат по макетам и коротко отчитаться, что сделано и что осталось.

## Правила

- Текстуры не перерисовывать и не масштабировать. Если чего-то не хватает — временная заглушка и пометка в отчёте.
- Все числа, которые ещё не утверждены (характеристики материалов, тиры рюкзака, объём фляги и т. п.), держать в одном месте, чтобы их легко было поменять.
- В обоих ТЗ есть разделы «Открытые вопросы». По ним не гадать: сделать самый простой рабочий вариант, явно пометить его в коде (`// TODO: уточнить`) и перечислить в отчёте.
- Коммитить после каждого законченного шага с понятным сообщением.
