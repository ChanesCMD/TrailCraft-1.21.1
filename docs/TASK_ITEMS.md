# ТЗ, часть 2: инструменты и предметы (NeoForge 1.21.1, modid `trailcraft`)

Все текстуры и модели уже лежат в архиве по путям проекта:
`src/main/resources/assets/trailcraft/textures/item/` и `.../models/item/`.
Общий вид всех предметов — `docs/preview_all_items.png`.

## 1. Что нужно сделать

1. Зарегистрировать все предметы из раздела 2 через `DeferredRegister.Items`.
2. Сделать собственные уровни материалов (Tier) для кремня, кости, аметиста, меди, бронзы и стали. Железо — ванильный `Tiers.IRON`.
3. Подключить готовые модели. Новые модели не рисовать: для каждого предмета уже есть JSON.
4. Добавить названия: содержимое `docs/lang/en_us.additions.json` и `docs/lang/ru_ru.additions.json` **дописать** в существующие `lang/en_us.json` и `lang/ru_ru.json`, не перезаписывая файлы.
5. Добавить все предметы во вкладку творческого режима мода.
6. Проверить в игре (раздел 6).

## 3. Классы и уровни

| Предмет | Класс | Примечание |
|---|---|---|
| Кирка, топор, лопата, кремнёвые инструменты | `PickaxeItem` / `AxeItem` / `ShovelItem` | как ванильные |
| Нож | `SwordItem` | слабее меча |
| Серп, коса | свой класс на основе `TieredItem` | поведение — открытый вопрос; пока только оружие/инструмент без особых действий |
| Пила, кусачки | свой класс на основе `DiggerItem` или `TieredItem` | поведение — открытый вопрос |
| Копьё | свой класс | бэкпорт копья из новых версий MC; пока — оружие ближнего боя с увеличенной дальностью (атрибут `entity_interaction_range`), детали уточнить |
| Лейки, линейка, метла | `Item` с `stacksTo(1)` | поведение — открытый вопрос |
| Палки | `Item` | обработанная палка получается тремя кликами ПКМ веткой по камню (решено раньше) |

Уровни материалов сделать через `SimpleTier` из NeoForge, все числа вынести в одно место (один класс или конфиг), чтобы потом легко менять. Значения ниже — **черновые**, только чтобы предметы работали:

## 4. Модели

- Все 16×16 инструменты, палки и метла — `parent: minecraft:item/handheld`. Лейки и линейка — `minecraft:item/generated`.
- **Копья и косы** держатся в руке длинными. У каждого две модели:
  - `<m>_spear.json` / `<m>_scythe.json` — загрузчик `neoforge:separate_transforms`: в инвентаре, на земле и в рамке показывается текстура 16×16, в руке — модель `_in_hand`;
  - `<m>_spear_in_hand.json` / `<m>_scythe_in_hand.json` — текстура 32×32 с увеличенным масштабом.
- Значения `display` (поворот, сдвиг, масштаб в руке) заданы на глаз. Подогнать в игре так, чтобы рука держала копьё и косу за нижнюю треть древка. Менять только `display`, текстуры не трогать.

## 6. Проверка

1. `./gradlew runClient`, открыть творческую вкладку мода.
2. У всех 52 предметов есть текстура и название на русском и английском (нет фиолетово-чёрных квадратов и ключей `item.trailcraft...`).
3. Копья и косы в руке длинные, в инвентаре — обычного размера.
4. Кирки, топоры и лопаты добывают свои блоки, ножи наносят урон.
5. В логе нет ошибок загрузки моделей.

5. Что делают серп, коса, пила, кусачки, лейка, линейка и метла.
