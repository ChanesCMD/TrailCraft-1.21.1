# Как работать над TrailCraft с двух ПК и телефона

Весь код лежит на GitHub, общая ветка — `main`. Каждый ПК — своя копия репозитория.
Миры, настройки игры и сборки (`run/`, `build/`) у каждого ПК свои и на GitHub не попадают.

## Ярлыки на рабочем столе

- **Запустить TrailCraft** (`scripts/play.bat`) — забирает с GitHub последние изменения и запускает игру с модом.
  Если на этом ПК есть незакоммиченные правки, обновление пропускается, чтобы их не потерять, и запускается
  то, что есть локально. Без интернета тоже запускается локальная версия.
- **Собрать TrailCraft** (`scripts/build.bat`) — собирает jar мода в `build\libs`.

Обоим нужна Java 21 (на Java 26 Gradle не запускается). Скрипты сами ищут JDK 21, а если её нет —
предлагают поставить через `winget`.

## Настройка нового ПК (один раз)

1. Установить Git: `winget install Git.Git` (или с git-scm.com).
2. Скачать проект: `git clone https://github.com/ChanesCMD/TrailCraft-1.21.1.git` в любую папку.
   Если копия на этом ПК уже есть — в её папке `git checkout main` и `git pull`.
3. Указать, как подписывать коммиты с этого ПК (в папке проекта):
   `git config user.name "ИмяНаGitHub"` и `git config user.email "почта аккаунта GitHub"`.
4. Запустить `scripts\make-shortcuts.bat` — появятся оба ярлыка.
5. Первый запуск ярлыка долгий (скачиваются Minecraft и NeoForge), дальше быстро.

## Правило работы с двух ПК

- **Сел работать** — сначала обновиться: ярлык «Запустить TrailCraft» делает это сам, или `git pull`.
- **Закончил** — закоммитить и запушить (Claude можно просто сказать «закоммить и запушь»).
- Если на двух ПК меняли одно и то же, `git pull` откажется обновляться — попросить Claude совместить изменения.

## С телефона

- **Управлять Claude на включённом ПК** (Remote Control): сессия идёт на ПК, телефон — только экран и
  клавиатура. Можно всё, что и за ПК: собирать, запускать игру, делать скриншоты. ПК должен быть включён
  и приложение Claude на нём открыто.
- **Облачная сессия Claude Code** (приложение Claude или claude.ai/code с подключённым GitHub): работает
  прямо с репозиторием, ПК не нужен, но игру не запустить. Чтобы облачная сессия могла пушить, у приложения
  Claude на GitHub должен быть доступ к репозиторию (его даёт владелец, ChanesCMD); без него будет ошибка 403.
- **Проверка без игры**: после каждого push GitHub сам собирает мод (вкладка Actions репозитория).
  Зелёная галочка — код компилируется, красный крестик — ошибка сборки.
